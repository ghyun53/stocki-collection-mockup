2캡처 화면 ① — 말풍선 + 진행바 + 아이콘 버튼

"오늘 +7.3%야! 😆 매우 신남" 말풍선, 초록 진행바, 아이콘 버튼

솔직한 정정 — 이 화면은 이 저장소의 React Native 코드로 그려지지 않습니다 확인됨 홈 화면은 UnityWebView(Unity로 만든 3D/2D 캐릭터 게임 화면)를 그대로 띄우는 구조입니다(HomeScreen.tsx:187~199). 말풍선 문구·진행바·아이콘 버튼은 Unity 프로젝트 쪽 화면 요소로, 그 Unity 프로젝트 자체는 이 저장소에 없어서 정확한 문구 로직은 코드로 보여드릴 수 없습니다. 대신 Unity에 어떤 주식 데이터가 전달되는지는 이 저장소의 코드(다리 역할을 하는 브릿지)에서 100% 확인 가능합니다.

데이터가 흘러가는 경로

말풍선 감정 문구의 기준값 추정 — 참고용 로직 이 저장소엔 Unity가 감정을 판단하는 코드가 없지만, 같은 로직을 TS로 미리 정의해 둔 참고 함수가 있습니다(src/utils/unityCalc.ts:55 calcEmotion(changeRate, volatilityGrade)). 변동성 등급별 임계값(EMOTION_THRESHOLDS)을 넘으면 감정 레벨 1~5를 반환합니다. Unity 쪽이 동일한 기준을 쓴다면, "😆 매우 신남"은 이 임계값을 넘는 고수익 구간일 가능성이 높습니다.

진행바 + 아이콘 버튼 추정

구조상 초록 진행바는 캐릭터 레벨/성장 진행률(StockDetailContent.tsx의 levelProgress와 동일 개념), 아이콘 버튼은 상세 화면 진입 또는 뉴스/관찰일지 버튼일 가능성이 높습니다 — 다만 이 두 요소는 Unity 캔버스 내부에 렌더링되어 이 저장소의 텍스트 검색으로는 정확한 소스를 확정할 수 없습니다. 확정하려면 Unity 프로젝트 소스 또는 담당 개발자 확인이 필요합니다.
